# Changelog

## 0.1.0

- Added iCalendar line unfolding and property parser.
- Added VCALENDAR / VEVENT parser with typed errors.
- Added DateTime utilities, Gregorian date arithmetic, and weekday calculation.
- Added RRULE parser for DAILY, WEEKLY, MONTHLY, and YEARLY recurrence.
- Added occurrence expansion with COUNT, UNTIL, BYDAY, BYMONTHDAY, BYMONTH, RDATE, and EXDATE.
- Added DURATION parsing and event metadata fields.
- Added validation diagnostics and query helper APIs.
- Added CLI, basic example, JSON/ICS export helpers, documentation, and CI.
